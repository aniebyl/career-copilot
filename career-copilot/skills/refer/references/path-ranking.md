# Ranking referral paths

Rank every candidate path by **warmth × usefulness**, then recommend the top 1–3.

## Warmth — how strong is the tie to the user?

| Tier | Path | Notes |
| --- | --- | --- |
| A | 1st-degree, strong tie | worked together, real relationship → best |
| B | 1st-degree, weak tie | connected but thin → still warm |
| C | 2nd-degree via a strong mutual | only if the mutual will actually vouch |
| D | Shared affiliation, not connected | same alma mater / past employer / community |
| E | Cold but relevant | no tie; use only if A–D are empty |

## Usefulness — how close to the hiring decision?

- **High:** the hiring manager, or someone on the exact team.
- **Medium:** adjacent team / same org under the same leader.
- **Low:** elsewhere in the company.

## Combine

Prioritize A/B at High or Medium usefulness. A warm tie to the *wrong* team only beats a
cold tie to the right one when the warm tie can **introduce you onward** — note that path
explicitly.

## For each top path, capture

- **Who** — name, title, where they sit — and the **true relationship hook**.
- **The ask** — intro to the hiring manager / direct referral / 15-min info chat.
- **Channel & timing** — LinkedIn DM, email, or a mutual intro.
- **Truthful framing** — never overstate closeness.

Hand the message itself to the `outreach` skill.
