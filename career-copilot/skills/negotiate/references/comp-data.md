# Comp data sources

Triangulate 2–3 sources; report a range + median with the sources named.

- **Levels.fyi** — tech comp by company / level / location (base, equity, bonus).
- **Glassdoor** — broad salary ranges + employee reviews across fields.
- **BLS OES** (bls.gov/oes) — occupational wage data for any field, by metro.
- **Payscale / Salary.com** — non-tech and generalist roles.
- **Web search** — "<role> <level> <company> salary <year>" for recent data points.

## How to use

- Adjust for **location, level, and company stage** (a seed startup ≠ a public company).
- For **equity**, state assumptions explicitly — current valuation, vesting schedule, dilution —
  and treat the dollar value as an estimate, not a promise.
- Note sample size / confidence; a single data point is a hint, not a benchmark.
- This is market information, **not financial advice** — the decision is the user's.
