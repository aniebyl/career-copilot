# Coaching metrics

Keep it simple and honest. With small samples, report direction, not false precision.

## Core metrics

- **Outreach reply rate** = replies / sent, split by pattern (warm ask · intro request · cold)
  and by opener. Want ~5 sends in a bucket before trusting a split.
- **Referral lift** = reply/advance rate with a warm path vs cold-apply.
- **Application response rate** = responses / applications, split by fit tier.
- **Stage conversion** = how many roles move stage → stage; find the leakiest stage.
- **Time-in-stage** = where roles stall (a stall is a signal too).

## Reading them

- Prefer **rates over counts**; always show the denominator.
- With n < 5 in a bucket, label it **provisional** — suggest, don't conclude.
- Look for **one or two high-leverage changes**, not a dashboard of micro-tweaks.

## Output → strategy.md

A living one-pager:

```
# Active strategy (updated <date>)
Do more of:        ...
Stop / fix:        ...
Default outreach:  ...   # the pattern with the best reply rate so far
Target focus:      ...   # role types / companies that actually advance
Provisional (low n): ...
```
