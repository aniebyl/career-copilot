# Live dashboard widgets (spec)

The dashboard (`pipeline-dashboard.html`) renders pipeline data embedded at generation time. To
make it *live*, add two panels that fetch on every open via `window.cowork.callMcpTool`.

## Panels

- **Upcoming interviews** — Calendar: next 7 days, events matching pipeline companies.
- **New replies** — Gmail: unread from known contacts / recruiter domains, matched to roles.

## Defensive pattern (wrap every connector call)

```js
async function live(name, args) {
  try {
    const r = await window.cowork.callMcpTool(name, args);
    return r.structuredContent ?? JSON.parse(r.content[0].text);
  } catch (e) { return null; }
}
// render the panel, or a "connect Calendar / Gmail" empty state when null
```

## Finalize step (one-time probe — required)

Per the artifact rule, only call tools whose output shape you've **verified this session**.
Before wiring: call the Calendar + Gmail tools once in chat, confirm their response shape, bind
the parser to what you observed, and list those tool names in `create_artifact`'s `mcp_tools`.

## Until then

The dashboard runs on the embedded pipeline snapshot, regenerated by `status` or the daily scout.
